# Sanity schemas (Phase 1 stub)

Create a Sanity project, then model:

- `banner` — homepage hero slides
- `aboutPage` — localized about content
- `faq` — FAQ items
- `testimonial` — customer quotes
- `galleryImage` — atelier / campaign gallery

Connect via `NEXT_PUBLIC_SANITY_PROJECT_ID`, `NEXT_PUBLIC_SANITY_DATASET`, `SANITY_API_TOKEN`.
